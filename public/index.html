What runs behind the scenes

POST

/collection → Newman

Your file is parsed in memory and executed through the same Newman engine you'd run from the CLI — every request, script, and assertion behaves identically.

DELETE

/headers, /tokens, /secrets

Request and response headers are stripped outright. Passwords, cookies, API keys, and JWTs are masked wherever they appear — even nested inside a response body.

GET

/failures — cross-checked, not guessed

Pass/fail is read from Newman's own failure log and matched back to the exact request that caused it, so nothing gets silently marked "passed."

PUT

/report — interactive, shareable

Filter by pass/fail, search by name, jump straight to the first failure, and inspect a redacted response body without leaving the page.
